# API Reference

Base URL (local): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

Start the server:
```powershell
uvicorn src.api.main:app --reload --port 8000
```

All endpoints below were tested with live curl requests against a running
server during development (not just written and assumed to work).

## GET /health
Returns pipeline readiness.
```json
{"status": "ok", "database_present": true, "analytics_artifacts_present": true}
```

## GET /kpis
Executive KPI snapshot, computed live from the database.
```json
{
  "total_orders": 170766,
  "otif_rate": 0.7082,
  "fill_rate": 0.92,
  "stockout_rate": 0.0478,
  "total_revenue_simulated": 7300000000.0,
  "avg_supplier_lead_time_days": 8.1,
  "estimated_annual_revenue_at_risk": 238361010.0,
  "forecast_wape_pct": 56.31
}
```

## GET /suppliers/risk?band={Low|Moderate|High|Critical}
Returns all suppliers' latest risk scores, sorted descending, with computed
root-cause evidence per supplier. `band` filter is optional.

## GET /inventory/risk?band={Low|Medium|High|Critical}
Returns all SKU-warehouse pairs' latest stockout risk, sorted descending,
capped at 200 rows, with computed root-cause evidence per pair.

## GET /forecast?product_id=&warehouse_id=
Returns actual-vs-predicted demand rows for the requested product/warehouse
(both filters optional), capped at 200 rows.

## GET /anomalies?limit=50
Returns the most recently detected anomalies with a human-readable reason
string per row (not just a raw score).

## GET /recommendations?urgency={Immediate|This week|This month}
Returns the prioritized action list from the recommendation engine.

## POST /ask
```json
// Request
{"question": "Why is supplier risk increasing?"}

// Response
{
  "question": "Why is supplier risk increasing?",
  "answer": "### INSIGHT\n...\n### EVIDENCE\n...\n### BUSINESS IMPACT\n...\n### RECOMMENDATION\n...\n### CONFIDENCE / LIMITATION\n...",
  "mode": "local_fallback",   // or "llm:anthropic" / "llm:openai" if LLM_API_KEY is set
  "matched_intents": ["supplier_risk"]
}
```

## POST /analyze
```json
// Request
{"entity_type": "sku", "entity_id": "SKU-00059"}
// or
{"entity_type": "supplier", "entity_id": "Acme Corp"}

// Response: the matching entity's full risk record (404 if not found, 400 if entity_type is invalid)
```

## Error handling

- `503` — an endpoint's required artifact hasn't been generated yet (run
  `scripts/run_pipeline.py` first).
- `404` — `/analyze` couldn't find the requested entity.
- `400` — `/analyze` received an invalid `entity_type`.

## Testing

`tests/test_api.py` uses FastAPI's `TestClient` (no live server required)
to test all endpoints, including filter behavior and error paths. Run with
`pytest tests/test_api.py -v`.
