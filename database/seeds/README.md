# database/seeds/

In a typical project this directory would hold static seed data (e.g., a
fixed list of regions or product categories to INSERT on first setup).

In SupplyIQ, all reference/dimension data is instead generated by
`src/data_generation/generate_dimensions.py` as part of the reproducible
simulation (fixed random seed — see `config.RANDOM_SEED`) rather than
hand-authored as static seed files. This was a deliberate choice: since the
whole dataset (including dimensions) needs to be internally coherent for
the ML models and root-cause analysis to work correctly (see
`docs/data_dictionary.md`), maintaining a separate hand-written seed file
alongside the generator would create two sources of truth that could drift.

If you need a fixed, non-random reference list for a real deployment (e.g.,
your company's actual list of warehouses), replace the relevant function in
`generate_dimensions.py` with a CSV read from this directory — the rest of
the pipeline doesn't care whether `dim_warehouse.csv` was generated or
hand-authored, only that it exists at `data/synthetic/dim_warehouse.csv`
with the expected columns.
